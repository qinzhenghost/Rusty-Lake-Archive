## 第一轮发现并已修复
1. 语言切换会重建段落文本，导致人物链接失效。
   - 修复：语言内容改为保留实体标记的 HTML 模板，并在切换后重新绑定实体交互。

2. 移动端“章节”按钮只是提示，没有真实 Bottom Sheet。
   - 修复：新增可打开 / 关闭的章节 Bottom Sheet。

3. 游玩进度只能临时勾选，没有本地持久化。
   - 修复：新增 `localStorage` 写入 / 读取逻辑。

4. 移动端“档案”入口只打开单个人物，不代表当前章节档案。
   - 修复：改为当前章节 Case Notes 抽屉，再从正文实体进入具体人物 / 概念档案。
