# Rusty Lake Archive — Step 02 页面信息架构

## 一级导航
- 首页 `/`
- 游戏档案 `/games`
- 时间线 `/timeline`
- 人物档案 `/characters`
- 游玩进度 `/progress`
- 阅读器 `/read/:game/:chapter`

## 核心页面模板
### 1. 首页
任务：建立氛围 + 让用户快速选择进入方式。
核心入口：开始阅读 / 按游戏 / 时间线 / 人物 / 防剧透设置。

### 2. 游戏档案
任务：按作品浏览，并区分已开放与待录入内容。
MVP 只完整开放 Seasons。

### 3. 剧情阅读器
桌面：左章节 / 中剧情 / 右 Case Notes。
移动：正文优先，章节与档案收纳为底部操作区。
不使用现代 Dashboard 卡片堆叠作为主阅读结构。

### 4. 人物档案
只展示当前游玩进度已经允许的信息。
人物在正文内可点击并通过侧栏打开，避免打断阅读。

### 5. 时间线
按故事发生时间组织，事件点击可回到剧情章节。
时间线是从“读故事”切到“理解世界”的核心桥梁。

### 6. 游玩进度
本地保存。勾选完成作品后解锁对应档案。
默认隐藏后续身份、结局、跨作品关系等高剧透信息。

## 阅读器信息层级
- Level 1：正文
- Level 2：当前章节 Case Notes
- Level 3：人物 / 概念抽屉
- Level 4：未解锁档案遮蔽层

## MVP 交互原则
1. 阅读不中断：人物和概念尽量侧栏/抽屉打开。
2. 剧透默认关闭：信息展示受用户进度约束。
3. 内容与 UI 分离：未来实际开发必须从内容 Schema 渲染。
4. 移动端正文优先：不把桌面三栏机械压缩到手机。
5. 不做攻略：不提供谜题答案、操作步骤。
